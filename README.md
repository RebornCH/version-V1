# เกมหมากรุกสากล (Chess Game)

เว็บแอปพลิเคชันเกมหมากรุกสากลที่สมบูรณ์ พร้อมฟีเจอร์ครบครัน

## ฟีเจอร์หลัก

### การเล่นเกม
- ♟️ กระดานหมากรุกมาตรฐาน 8x8
- 🎮 รองรับผู้เล่น 2 คน (ขาว vs ดำ)
- ✅ กฎกติกาหมากรุกสากลครบถ้วน
- 🏰 Castling (เข้าป้อม)
- 🔄 En Passant
- 👑 Pawn Promotion (โปรโมทเบี้ย)
- ⚠️ ตรวจสอบ Check และ Checkmate
- 🤝 เสมอ (Stalemate, Insufficient Material, Threefold Repetition)

### ระบบเวลา
- ⏱️ นาฬิกาจับเวลาสำหรับแต่ละฝั่ง
- 🔔 แจ้งเตือนเมื่อหมดเวลา
- ⚙️ ปรับแต่งเวลาได้ในการตั้งค่า

### อินเทอร์เฟซ
- 🎨 UI สวยงาม ทันสมัย
- 🌓 รองรับหลายธีม (คลาสสิก, น้ำเงิน, เขียว, ไม้)
- 📱 Responsive Design (รองรับมือถือและแท็บเล็ต)
- 🔊 เสียงเอฟเฟกต์เมื่อเดินหมากและกินหมาก
- 💡 ระบบแนะนำการเดิน
- ↩️ ย้อนกลับการเดินได้

### ประวัติและการติดตาม
- 📜 แสดงประวัติการเดินทั้งหมด (Algebraic Notation)
- 🏆 แสดงหมากที่ถูกกิน
- 🎯 ไฮไลท์ตาเดินล่าสุด
- 🔍 ไฮไลท์ตำแหน่ง King เมื่อถูกเช็ค

### คีย์ลัด
- `Ctrl+N` - เกมใหม่
- `Ctrl+Z` - ย้อนกลับ
- `Ctrl+F` - หมุนกระดาน
- `Ctrl+H` - คำแนะนำ
- `Escape` - ยกเลิกการเลือก

## วิธีใช้งาน

1. เปิดไฟล์ `index.html` ในเบราว์เซอร์
2. คลิกที่หมากเพื่อเลือก
3. คลิกที่ช่องสีเขียวเพื่อเดินหมาก
4. ใช้ปุ่มควบคุมด้านล่างสำหรับฟังก์ชันต่างๆ

## โครงสร้างไฟล์

```
/workspace
├── index.html      # หน้าเว็บหลัก
├── styles.css      # สไตล์และธีม
├── chess.js        # โลจิกเกมหมากรุก
├── script.js       # UI Controller
└── README.md       # เอกสารนี้
```

## เทคโนโลยีที่ใช้

- HTML5
- CSS3 (พร้อม Animations)
- JavaScript (Vanilla ES6+)
- Web Audio API (สำหรับเสียง)
- LocalStorage (บันทึกการตั้งค่า)

## การปรับแต่ง

สามารถปรับแต่งได้ที่เมนู "ตั้งค่า":
- เวลาต่อฝั่ง (1-60 นาที)
- ชื่อผู้เล่น
- ธีมสีกระดาน
